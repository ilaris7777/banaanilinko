# Banaanilinko

Fysiikkapeli, jossa banaani lingotaan koreihin. Kuusi maailmaa, 72 tasoa ja yhteinen top 10 -ennätyslista jokaiselle maailmalle.

Pelaa: https://ilaris7777.github.io/banaanilinko/

Peli on yksi tiedosto (`index.html`), joka toimii myös ilman nettiä. Ennätyslista käyttää Supabasea; osoite ja julkinen avain ovat `CONFIG.online`-kohdassa.
